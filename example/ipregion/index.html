ipregion

替换 czdb / qqwry 的 IP 地域库：一份 ipregion.db 覆盖 IPv4 / IPv6。 查询前需准备该文件（约定名，常量 db.FileDB）。

介绍

获取 ipregion.db： Releases · ipregion-db 下载现成库，或按 制库文档 用 maker/czdb 自行生成。建议放到 example/ipregion/ipregion.db，或启动参数 -db。

方向GoHTTP
打开库 / 摘要 Open / Meta GET /ipregion/api/meta
IP → 地域 + ISP Find / FindAddr GET /ipregion/api/find?ip=
地域 ID → 全部信息（含上级链） Area GET /ipregion/api/area?id=
取直接下级（parent_id=0 为顶级） Areas GET /ipregion/api/areas?parent_id=
运营商 ID → 名称 ISP GET /ipregion/api/isp?id=
运营商列表 / 名称搜索 ISPs / SearchISPs GET /ipregion/api/isps · ?q=
地域 → IP 段（含全部下级） FindRanges GET /ipregion/api/ranges?area_id=&v4=&v6=
运营商 → IP 段 FindISPRanges GET /ipregion/api/isp-ranges?isp_id=&v4=&v6=

Find / Area 的 Area 带 Parent 上级链； Areas 返回字典节点（id / parent_id / name）。 FindAddr 仅 Go 侧使用（已解析的 netip.Addr）。

Meta

Open("ipregion.db") → Meta()

库摘要：版本、备注、地域/ISP 数、IPv4/IPv6 段数。

{}

Find

Find(ip) / FindAddr(addr)

IPv4 / IPv6 同一接口，返回行政区划（含上级链）和 ISP。留空 IP 时用本机地址。

{}

地域

Areas(parentID) → FindRanges(areaID)

级联下拉选择地域（含下级），再反查该节点的全部 IP 段。

StartEnd地域ISP

运营商

ISPs() → FindISPRanges(ispID)

下拉为全部运营商；可先筛选名称，选中后反查该 ISP 的全部 IP 段。

StartEnd地域ISP
